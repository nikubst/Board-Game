SEO Instructions for NIKOO Art Studio

1) Deploy your site to a production domain (e.g. https://your-domain.com).

2) Verify ownership in Google Search Console:
   - Go to https://search.google.com/search-console
   - Add property -> URL prefix -> enter your production URL
   - Verify using recommended method (HTML file upload, DNS TXT record, or using your hosting provider).

3) Submit sitemap:
   - Ensure `https://your-domain.com/sitemap.xml` is reachable.
   - In Search Console, go to Sitemaps -> enter `sitemap.xml` -> Submit.

4) Check `robots.txt`:
   - Ensure `https://your-domain.com/robots.txt` is reachable and points to your sitemap.

5) After submission:
   - Use "URL Inspection" to request indexing for critical pages.
   - Monitor Coverage report and Fix any errors.

6) Quick on-page SEO checklist:
   - Unique `title` and `meta description` per page.
   - Use `og:` OpenGraph tags for sharing.
   - Add `alt` text to images.
   - Use structured data (JSON-LD) for Organization and WebSite.

7) Performance:
   - Run Lighthouse and fix Core Web Vitals issues.
   - Serve images optimized and enable caching/CDN.
